# 退相干时间 T₂ 解释

**退相干时间 T₂** 是量子计算中一个核心指标，它描述了量子比特**相位信息能够保持的时间长度**。

简单来说：即使你将量子比特制备在某个叠加态（比如 \(|0\rangle + |1\rangle\)），由于环境噪声（如磁场波动、电荷噪声、热涨落等），比特的相位会发生不确定的漂移。经过时间 T₂ 后，相位信息基本丢失，叠加态退化为完全的混合态，无法再进行相干操控。

## 🧠 T₂ 与 T₁ 的区别

- **T₁（能量弛豫时间）**：比特从 \(|1\rangle\) 自发衰落到 \(|0\rangle\) 的时间，反映**能量耗散**。  
- **T₂（退相干时间）**：比特叠加态的相位随机化时间，反映**相位信息的丢失**。  

通常 **T₂ ≤ 2 T₁**（受 T₁ 限制）；若纯退相位（无能量耗散），则 T₂ 约等于 T₁ ~ 2T₁ 之间。

## 📏 如何测量 T₂？

### 1. Ramsey 实验（测量 T₂*，包含非均匀展宽）

脉冲序列：  

\[
\pi/2 \ \text{脉冲} \ \xrightarrow{\text{等待时间 } \tau} \ \pi/2 \ \text{脉冲} \ \xrightarrow{\text{测量}}
\]

- 扫描等待时间 \(\tau\)，观测到振荡信号（频率为失谐量），其**包络衰减**的时间常数即为 **T₂***（带星号，包含所有低频噪声引起的退相干，通常较短）。

### 2. Spin Echo（Hahn Echo）实验（测量真正的 T₂，消除静态失谐）

脉冲序列：  

\[
\pi/2 \ \text{脉冲} \ \xrightarrow{\text{等待 } \tau/2} \ \pi \ \text{脉冲} \ \xrightarrow{\text{等待 } \tau/2} \ \pi/2 \ \text{脉冲} \ \xrightarrow{\text{测量}}
\]

- \(\pi\) 脉冲可将静态非均匀失谐“重聚焦”，消除低频噪声影响。得到的衰减时间常数即为 **T₂**（通常比 T₂* 长很多）。
